# Portfolio Revalino Julian Nggebu

Portfolio multi-halaman menggunakan HTML, CSS, dan JavaScript.

## Menjalankan
1. Ekstrak file ZIP.
2. Buka `index.html` di browser.
3. Klik **Buka Profile Saya** untuk masuk ke `home.html`.
4. Setiap menu navbar membuka halaman terpisah:
   - `home.html` — Beranda
   - `about.html` — Tentang Saya
   - `skills.html` — Keahlian
   - `projects.html` — Project
   - `hobbies.html` — Hobi
   - `contact.html` — Kontak

## Mengatur akun media sosial
Buka `contact.html`, lalu ganti `USERNAME_IG` dan `USERNAME_GITHUB` dengan username milikmu. Logo Instagram dan GitHub ditampilkan dari Simple Icons CDN, jadi koneksi internet diperlukan agar logo termuat.

## Catatan
- Ubah email, detail diri, skill, hobi, dan project contoh agar sesuai dengan data asli.
- Formulir kontak saat ini hanya melakukan validasi di browser; belum mengirim pesan ke email/backend.
- Tema terang/gelap disimpan di browser.
